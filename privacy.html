Wealth Logic Uploader: Privacy Policy

Last updated: 11 September 2026

Wealth Logic Uploader ("the app") is a private publishing tool operated by the owner of the Wealth Logic YouTube channel (@wealth_logic_daily). It is not offered to the public, and its only user is the channel owner.

What the app accesses

The app uses YouTube API Services. With the channel owner's explicit consent through Google sign-in, it requests these permissions:

  • youtube.upload: to upload videos the channel owner produced to their own channel.
  • youtube: to set video thumbnails and read the channel's own basic details (title and handle), to confirm uploads go to the correct channel.

The app does not access any other user's YouTube account, data, comments, or analytics.

What the app stores

  • An OAuth token issued by Google, stored in a file on the owner's private server. It is readable only by the server's administrator and is never shared or transmitted anywhere except to Google's own APIs.
  • The IDs of videos the app uploaded and their publish times, stored in a local database on the same server, so the app avoids duplicate uploads and schedule clashes.

The app stores no personal information about viewers or any other YouTube users. It uses no cookies, analytics, or advertising trackers.

Sharing

The app does not sell, share, or transfer any data to third parties. Data from YouTube API Services is used only to publish the channel owner's own videos.

Retention and deletion

  • Video IDs are kept for as long as the channel owner operates the tool.
  • The OAuth token is kept until it is revoked.
  • To delete stored data, the channel owner deletes the token file and the local database from the server.
  • Access can be revoked at any time from Google's security settings: https://security.google.com/settings/security/permissions. After revocation the app can no longer access the account, and any stored token stops working.

Google and YouTube policies

By using the app, the channel owner agrees to be bound by the YouTube Terms of Service: https://www.youtube.com/t/terms. The app's use of information received from Google APIs follows the Google Privacy Policy (https://policies.google.com/privacy) and the Google API Services User Data Policy, including its Limited Use requirements.
